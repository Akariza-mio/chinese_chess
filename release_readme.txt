中国象棋（Windows x64）

运行方法：
1. 请先完整解压压缩包，不要直接在压缩包内运行。
2. 双击 ChineseChess.exe。

局域网联机：
1. 两台电脑连接同一个 Wi-Fi 或同一个局域网。
2. 红方点击“创建联机”，把画面显示的局域网地址告诉黑方。
3. 黑方点击“加入联机”，输入红方的地址并按回车。
4. Windows 防火墙首次询问时，创建联机的一方需要允许“专用网络”访问。

请保留 ChineseChess.exe、raylib.dll 和 assets 文件夹的相对位置。
本游戏无需安装 Visual Studio、C++ 编译器或 raylib。

这是未经过商业代码签名的个人项目。Windows SmartScreen 可能显示未知发布者，
请只在确认压缩包来自可信来源时运行。
